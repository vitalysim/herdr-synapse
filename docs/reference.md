# Herdr Synapse command and shortcut reference

This is the complete user-facing index for the Synapse CLI, plugin actions,
console language, and keyboard controls. For exact JSON response and error
contracts, see the [CLI contract](cli.md). For behavior, security boundaries,
and verification status, see the [capability matrix](capabilities.md).

The fastest live lookup is:

```bash
herdr-synapse --help
herdr-synapse <command> --help
herdr-synapse keys print
herdr-synapse keys check
herdr-synapse setup --print-config
```

In shortcut notation, `prefix+t` means press Herdr's prefix key, release it,
then press `t`. Herdr's default prefix is `Ctrl+B`, so the default sequence is
`Ctrl+B`, then `T`. Your configured prefix always wins.

## Teams view

Open it with `prefix+t`, `herdr-synapse ui picker`, or the
`herdr-synapse.team-up` action. It shows every team, its manager and members, team-to-team links, and unassigned agents grouped under their Herdr tab label and stable tab ID. Every agent row still shows its pane ID, and the ID disambiguates tabs that share a label.

### Team tree

| Key | Result |
| --- | --- |
| `Up` / `k`, `Down` / `j` | Move one row. |
| `PageUp`, `PageDown` | Move one visible page. |
| `Home`, `End` | Move to the first or last row. |
| `Left` / `h`, `Right` / `l` | Collapse or expand a team or tab; Left on a member returns to its team row, and Left on an unassigned agent returns to its tab row. |
| `Space` | Select an unassigned agent, or fold/unfold a team, tab, or section. |
| `a` | Select all visible unassigned agents, or clear the selection. |
| `Enter` | Open a member's actions; fold a team or a tab when nothing is selected; add selected agents to a team; or advance the create-team wizard. |
| `g` | Verify and focus the highlighted agent's pane, then close the Teams view. Works for team members and unassigned agents. |
| `b` | Open the highlighted team's board in its own console. |
| `s` | Restore the highlighted team's missing agents into a new named tab. Saved conversations resume; members without a conversation ID start fresh with saved settings and instructions. |
| `c` | Choose another team to link or unlink through their managers. |
| `v` | Open the ASCII organization topology. |
| `f` | Set or change the highlighted team's project folder. |
| `x` | Ask to dissolve the highlighted team. Its board is archived and its agents keep running. |
| `w` | Show unassigned agents from the current Herdr space or from every space. |
| `r` | Refresh teams and agents. |
| `Esc` / `q` / `Ctrl+C` | Close the view. |

Destructive confirmations use `y` to continue and `n` or `Esc` to cancel.
`Enter` deliberately does not confirm them.

Restore runs immediately and shows progress while agents start; arrow and page keys remain available to scroll. The picker stays open during startup. Running agents and existing reserved panes are skipped. Success opens the restored tab; partial failures open a scrollable results view with every member's outcome. Use arrows, PageUp/PageDown or Home/End to read all results, `g` to inspect the restored tab, and `Esc` to return to the team tree. Existing board history, unread positions, member roles, manager assignment and team links are retained. A recorded conversation that fails to resume is reported as a failure, never silently replaced. Close an unusable reserved pane before retrying restore, or resolve its prompt and bind the member manually.

### Organization topology

| Key | Result |
| --- | --- |
| `Up` / `k`, `Down` / `j` | Scroll one line. |
| `PageUp`, `PageDown` | Scroll one page. |
| `Home`, `End` | Jump to the beginning or end. |
| `r` | Refresh the live topology. |
| `v` / `Esc` / `q` | Return to the team tree. |

The topology is read-only. Links connect team managers; both teams must have a
manager before a link can be created.

### Member action menu

Press `Enter` on a member. Use `Up`/`k` and `Down`/`j`, then `Enter`, or press
the action number directly. `Esc` or `q` returns to the tree.

| Number | Action |
| --- | --- |
| `1` | Rename the member and its Herdr agent. |
| `2` | Change the member's goal. |
| `3` | Send the saved goal to the member now. |
| `4` | Remove the member and clear its Herdr agent name. |
| `5` | Remove the member but keep its Herdr agent name. |
| `6` | Focus the member's pane and close the popup. |
| `7` | Show the command that resumes the member's own agent session. |
| `8` | Make the member the team manager, or clear it if already manager. |
| `9` | Set the member's model and effort. |
| `0` | Swap agent: create a fresh replacement with the member's configuration, or retry its unfinished replacement. |

The swap form selects Claude Code, Codex, OpenCode, or Pi and optional model/effort.
`y` confirms creation and closing the outgoing pane. The replacement gets a
new conversation and a handoff in a new tab; no pre-existing agent is needed.

### Link chooser and team wizard

| Screen | Keys |
| --- | --- |
| Link chooser | `Up`/`k`, `Down`/`j` move; `Enter` links or unlinks; `Esc` returns. |
| Existing-team chooser | Arrow keys or `j`/`k` move; number or `Enter` chooses; `Esc`/`q` returns. |
| Text fields | Left/Right move; Home/End or `Ctrl+A`/`Ctrl+E` jump; Backspace/Delete edit; `Ctrl+U` clears; `Ctrl+K` deletes to the end; `Enter` accepts; `Esc` goes back. |
| Charter | `Enter` adds a line; an empty line after content, `Alt+Enter`, or `Ctrl+D` finishes; `Tab` skips; `Ctrl+O` loads a file. |
| Team rules | After the charter, the same multiline keys add optional DOs and DON'Ts; `Tab` skips; `Ctrl+O` loads a file. |
| Project folder | `Enter` accepts the suggested or typed folder; `Tab` skips it. |
| Member Mission / brief | Required for every selected member; empty `Enter` stays on the field and explains what is missing. |
| Final confirmation | `Enter` creates the team or adds the selected agents; `Esc` returns. |

Bracketed paste is accepted in text fields without treating pasted control
characters as actions.

## Team console

Open the current space's team with `prefix+u`, `herdr-synapse ui console`, or
the `herdr-synapse.console` action. A session can have one console per team;
`b` in the Teams view opens the highlighted team's board directly.

Inter-team messages stand out in bold magenta with `[⇄ TEAM IN]` or `[⇄ TEAM OUT]` badges, including in the full feed. Direction is relative to the board you are viewing. Wrapped lines keep the same style; monochrome terminals retain bold text and ASCII mode uses `<->`. Use `/filter teams` to isolate this traffic or `/filter all` to show everything.

### Console keys

| Key | Result |
| --- | --- |
| `Enter` | Submit the input line. During a destructive confirmation, it also confirms. |
| `Alt+Enter` | Insert a newline without submitting. |
| Left/Right | Move within the input. |
| Home/End or `Ctrl+A`/`Ctrl+E` | Move to the beginning or end of the input. While scrolled back, `End` returns to the newest post. |
| Backspace/Delete | Delete before or under the cursor. |
| `Ctrl+U` | Clear the input. |
| `Ctrl+K` | Delete from the cursor to the end. |
| `Up`, `Down` | Scroll the board one entry when no completion menu is open. |
| `PageUp`, `PageDown` | Scroll the board ten entries. |
| `Tab` | Complete the highlighted menu item, or cycle board filters when no menu is open. |
| `?` on an empty line | Open the complete in-console help. |
| `Esc` | Hide a menu/status/help box or return to and follow the newest post. |
| `Ctrl+C` | Clear a non-empty input; close the console when the input is empty. |
| `y` / `n` | Confirm or cancel a destructive console action. |

Typing `/`, `@`, `@@`, or `!` opens the command, member, file, or direct-member
menu. `Up`/`Down` moves, `Tab` completes, and `Esc` hides the menu. `Enter`
also completes names and files; in the `/` menu it executes the line as typed.

### Message and recipient syntax

| Syntax | Result |
| --- | --- |
| `text` | Post to the whole current team. |
| `@name text` | Post to one member. |
| `@role:r text` | Post to every member with that role. |
| `/team other-team text` | Post through an active link; the other team's manager is nudged. |
| `/human text` | Write a note addressed only to the human. |
| `@@path text` | Attach a file; bare `@@` opens the file finder. |
| `!name text` | Type only if that member is still idle at atomic submission; every attempt is recorded. |
| `!!name text` | Also permit typing while the member is working or muted, but never into a dialog or existing draft. |
| `!!all text` | Attempt that forced direct delivery separately for every current agent; each target gets its own record and outcome. |
| `/all !text` | Post literal text beginning with `!` instead of treating it as direct typing. |

## Compose popup

Open it with `prefix+m`, `herdr-synapse ui compose`, or the
`herdr-synapse.compose` action. It uses the console's recipient and post
syntax, except direct typing with `!` is console-only.

| Key | Result |
| --- | --- |
| `Enter` | Post and close after success; a refused post stays editable. |
| `Esc` / `Ctrl+C` | Cancel and close. |
| `Alt+Enter` | Insert a newline. |
| `@`, `@@`, `/` plus `Up`/`Down`, `Tab`, `Esc` | Open, navigate, complete, or close an autocomplete menu. |
| Standard text-editing keys | Left/Right, Home/End, `Ctrl+A`/`Ctrl+E`, Backspace/Delete, `Ctrl+U`, and `Ctrl+K` behave as in the console. |

## Asks popup

The notifier opens this only when an unresolved ask is actually waiting for
the human. `/asks` shows the pending list inside the console, and
`herdr-synapse asks` prints it in a shell; neither forces an empty popup open.

| Key | Result |
| --- | --- |
| `Enter` | Reply with the typed answer. |
| `Ctrl+A` | Acknowledge the current ask and unblock the waiting agent. |
| `Tab` / `Down` | Move to the next ask. |
| `Shift+Tab` / `Up` | Move to the previous ask. |
| `Esc` | Clear typed text first; otherwise leave the ask waiting and stop reopening it automatically. |
| `q` / `Ctrl+C` | Close when the input is empty. |
| Backspace | Edit the answer. |
